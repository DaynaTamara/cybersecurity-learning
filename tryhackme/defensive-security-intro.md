TryHackMe: Introduction to Defensive Security

Lab Overview

- Platform: TryHackMe
- Area: Defensive Security
- Focus: Security Operations Center (SOC) and Incident Response

Objective

Learn how a Security Operations Center (SOC) monitors suspicious activity, investigates security alerts, and responds to potential cyberattacks.

Investigation

During this lab, I investigated suspicious login attempts against Fake Bank. The security dashboard reported repeated failed login attempts associated with the threat actor known as Shadow Figures.

The investigation focused on the account "dave.saunders" and the "/login" page.

Threat Intelligence

I reviewed the threat intelligence report for Shadow Figures and learned about the group's techniques, including:

- Brute-force attacks.
- Credential stuffing.
- Use of valid accounts.
- Attempts to hide the attacker's origin through proxies or other infrastructure.

Defensive Actions

- Investigated the suspicious login alert.
- Disabled the targeted account as instructed by the lab.
- Updated the threat intelligence log with the incident details.
- Created an incident report documenting the investigation.

Key Learnings

This lab helped me understand the importance of monitoring security alerts, investigating authentication anomalies, using threat intelligence, and documenting incidents.

I also learned how incident response activities help security teams protect organizational systems and improve future detection and response.

Tools and Concepts

- Security Operations Center (SOC)
- Security monitoring dashboards
- Threat intelligence
- Brute-force attacks
- Account security
- Incident reporting

Conclusion

This exercise provided practical exposure to a defensive security workflow, from detecting suspicious login activity to documenting the incident.
